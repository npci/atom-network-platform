# AtOM — Authors & Contributors

This file lists the people and organisations who have contributed to
AtOM. It is maintained manually — if your name is missing,
please open a pull request to add it.

---

## Core Team

Copyright is held collectively by the contributors, credited in `LICENSE` and
`NOTICE` as "The ATOM Authors". Day-to-day maintenance sits with the
maintainers in [CODEOWNERS](CODEOWNERS), which is the handle every review routes
to and the authoritative answer to "who owns this code".

---

## Contributors

Contributions are tracked via git history and GitHub pull requests.
All contributors who have signed off commits with the DCO are credited
through the git log.

To see all contributors:

```bash
git log --format="%aN <%aE>" | sort -u
```

# Getting Support

This document explains where to get help with AtOM.

---

## Documentation

The best first stop is the documentation, which covers:

- **Getting Started** — installation, configuration, first run
- **User Guide** — features, LLM configuration, connectors
- **Developer Guide** — architecture, API reference, extending the platform
- **Deployment Guide** — bare-metal, Docker, Kubernetes

---

## GitHub Issues

For **bug reports** and **feature requests**, open an issue:

- [Bug report](.github/ISSUE_TEMPLATE/bug_report.md)
- [Feature request](.github/ISSUE_TEMPLATE/feature_request.md)

Before opening an issue, please search existing issues to avoid duplicates.

---

## Community

- **Discussions** — use GitHub Discussions for questions, ideas, and general conversation.
- **Pull Requests** — contributions are welcome. See [CONTRIBUTING.md](CONTRIBUTING.md).

---

## What is NOT supported here

- Deployment on specific proprietary infrastructure
- Custom integrations not covered by the public API
- Issues caused by modifications to the platform outside of the documented extension points

---

*For enterprise support options, contact the maintainers via the repository.*
